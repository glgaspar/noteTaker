What to send

A JSON object, up to 64 KB. These fields are read, and the full payload is kept for you to see:

  • title (or subject, name, summary): the task
  • body (or description, details, text, message): its details
  • due: a date, 2026-11-30
  • id: optional; an item resent with the same id is not added twice

Plain text works too: the first line becomes the title.

curl -X POST <url> -H 'Content-Type: application/json' \
  -d '{"title": "Renew passport", "due": "2026-12-01"}'
{{end}}
